## Dataset

This project uses the **Online Retail II UCI** dataset from Kaggle.

**Dataset:** https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci

The dataset is not included in this repository. Please download it from the link above.

- The dataset was downloaded from Kaggle and preprocessed before analysis.
- 
- During preprocessing, invalid or unnecessary records were removed as part of the data cleaning pipeline.

> Note: The original dataset available on Kaggle may differ in size from the processed dataset used during development.
